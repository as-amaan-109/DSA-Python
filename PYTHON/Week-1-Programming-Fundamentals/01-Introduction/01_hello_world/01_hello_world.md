# 🔍 Understanding the Code

Consider:

```python
print("Hello World")
```

There are two important parts:

### `print`

`print` is the name of Python's built-in function used to display output.

### `"Hello World"`

`"Hello World"` is a **string**.

A string is a sequence of characters.

---

# 💻 First Python Program

```python
print("Hello World")
```

Output:

```text
Hello World
```

This is our first Python program.

---

# 📝 Printing Text

We can print any text by putting it inside quotes.

```python
print("Hello")
print("Welcome to Python")
print("I am learning Python")
```

Output:

```text
Hello
Welcome to Python
I am learning Python
```

---

# 🔢 Printing Numbers

We can also print numbers.

## Integer

```python
print(22)
```

Output:

```text
22
```

## Float

```python
print(22.5)
```

Output:

```text
22.5
```

# ✅ Printing Boolean Values

Python has Boolean values:

```text
True
False
```

Example:

```python
print(True)

```

Output:

```text
True

```

---

# 📌 Important Point

Text should normally be written inside quotes:

```python
print("Hello")
```

Numbers do not require quotes:

```python
print(100)
```

Compare:

```python
print("100")
print(100)
```

Both may display:

```text
100
100
```

But internally they are different:

```text
"100" → String
100   → Integer
```

We will study data types in detail later.

# ⚠️ Common Mistakes

## Mistake 1: Forgetting quotes

Incorrect:

```python
print(Hello World)
```

Correct:

```python
print("Hello World")
```

---

## Mistake 2: Incorrect capitalization

Python is case-sensitive.

This is correct:

```python
print("Hello")
```

This is not the same:

```python
Print("Hello")
```

Python will not treat `Print` as the built-in `print()` function.

---

## Mistake 3: Missing Parentheses

Incorrect:

```python
print "Hello"
```

Correct:

```python
print("Hello")
```
