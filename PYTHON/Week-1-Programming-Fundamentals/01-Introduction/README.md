# Python Introduction

Welcome to the **Python Introduction** section of the DSA-Python learning repository.

This section introduces the fundamentals of Python programming. It is designed to help beginners understand how Python programs display output, represent information, and handle special characters in strings.

The goal is to establish a strong foundation before moving on to variables, data types, operators, conditional statements, loops, functions, and Data Structures and Algorithms (DSA).

---

## About This Section

- **Week:** 1 – Programming Fundamentals
- **Section:** 01 – Introduction
- **Level:** Beginner
- **Programming Language:** Python
- **Main Focus:** Basic Syntax, Output, Strings, and Escape Sequences

## Learning Objectives

After completing this section, you should be able to:

- Understand the purpose of Python programming.
- Write and run your first Python program.
- Display text, numbers, Boolean values, and variables.
- Understand the `print()` function and its parameters.
- Format output using separators, line endings, and f-strings.
- Work with common escape sequences in Python strings.
- Understand raw strings and Unicode escapes.
- Read and analyse beginner-level Python code.
- Solve basic output-related programming problems.
- Develop the habit of practising and testing code independently.

## Standard Followed for Every Topic

Each topic in this repository follows a consistent practice structure.

### Python File (`.py`)

Each topic's Python file contains:

- **12 examples** that explain the core concepts.
- **12 solved practice questions** with working answers.
- **5 independent practice questions** without solution code.
- Comments and descriptive function names.
- A menu system to run individual examples or questions.
- Practical outputs and relevant edge-case handling.

This approach allows you to practise one task at a time without executing every example together.

### README File (`README.md`)

Each topic's README includes relevant learning material such as:

- Definition and introduction
- Learning objectives
- Detailed theory and syntax
- Examples with explanations
- Expected outputs
- Important terminology
- Common mistakes and troubleshooting
- Solved-question overview
- Independent practice questions
- Interview questions and answers
- Completion checklist and learning outcomes

The level of detail depends on the topic. Only relevant concepts are included; advanced material is introduced when appropriate.

## How to Study This Section

Use the following workflow for every topic.

### Step 1: Read the Theory

Start with the topic's `README.md`. Understand the concepts before copying or running code.

### Step 2: Study the Examples

Open the `.py` file and read the comments and function names. Predict what each example will display.

### Step 3: Run the Code

Execute the Python file and select individual examples from its menu.

### Step 4: Understand the Output

Compare the actual output with your prediction. Identify which line of code produced each result.

### Step 5: Practise the Solved Questions

Run all 12 solved questions. Understand the reasoning behind each answer instead of memorising the code.

### Step 6: Solve the Independent Questions

Attempt the 5 unsolved questions without looking for ready-made solutions. Write your own code and test it.

### Step 7: Revise

Review the concepts, correct mistakes, and make sure you can explain the code in your own words.

## Common Beginner Mistakes

Pay attention to these common issues while studying:

- Forgetting quotation marks around text.
- Using incorrect capitalization for Python Boolean values.
- Confusing string values with numeric values.
- Misunderstanding the `sep` and `end` parameters.
- Writing escape sequences incorrectly.
- Expecting special control characters to display identically in every terminal.
- Copying code without understanding its output.
- Skipping practice questions and relying only on examples.

The purpose of this section is to understand the basics clearly, so take time to test small changes in your code.
