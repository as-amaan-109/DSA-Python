# Flowcharts and Algorithms

Welcome to **Flowcharts and Algorithms**, a section of the Python Programming Fundamentals journey.

This section focuses on developing problem-solving skills by learning how to design algorithms, represent solutions using flowcharts, and understand the step-by-step logic required to solve programming problems.

Before writing code, it is important to understand **what problem we are solving, how we will solve it, and in what order the steps should execute.**

## 🔷 Common Flowchart Symbols

| Symbol | Name | Purpose |
|---|---|---|
| Oval | Terminal | Represents Start or End |
| Rectangle | Process | Represents calculations or instructions |
| Parallelogram | Input/Output | Represents reading input or displaying output |
| Diamond | Decision | Represents a condition with possible branches |
| Arrow | Flow Line | Shows the direction of execution |
| Circle | Connector | Connects different parts of a flowchart when needed |

These symbols help make program logic easier to understand and communicate.
