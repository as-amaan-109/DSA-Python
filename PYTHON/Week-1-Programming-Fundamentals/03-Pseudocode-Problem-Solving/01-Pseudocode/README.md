# Pseudocode

Welcome to the **Pseudocode** section of Python Programming Fundamentals.

Pseudocode is a simple way to describe the logic of a program using human-readable instructions. It helps us plan a solution before writing actual code in a programming language such as Python.

In this section, you will learn how to represent basic operations, input/output, conditional statements, and loops using pseudocode.

## 🧠 Example: Add Two Numbers

### Problem

Write a solution that accepts two numbers and displays their sum.

### Pseudocode

```text
START
    INPUT A
    INPUT B
    SUM = A + B
    OUTPUT SUM
END
```

### Python Implementation

```python
# Problem: Add two numbers

a = int(input("Enter the first number: "))
b = int(input("Enter the second number: "))

total = a + b

print("Sum:", total)
```

### Sample Output

```text
Enter the first number: 10
Enter the second number: 20
Sum: 30
```

The pseudocode explains the logic without depending on Python syntax. The Python implementation translates that logic into executable code.
