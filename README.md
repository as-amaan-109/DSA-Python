# ⏱️ Complexity Analysis

For important algorithms, I will track:

### Time Complexity

How the running time grows with input size.

### Space Complexity

How much additional memory is required.

Example:

```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

```text
Best Case    → O(1)
Average Case → O(n)
Worst Case   → O(n)
Space        → O(1)
```
